# Iris navigation decision

The production interface follows the task-oriented direction validated in the
2026 UX prototype. It borrows the low cognitive load of modern photo libraries
without hiding Iris-specific capabilities.

Primary destinations:

- **Inicio**: natural-language search, recent media, and common tasks.
- **Fotos**: the complete media timeline.
- **Buscar**: text, image, person, and optional advanced filters.
- **Organizar**: collections, people, duplicate review, learned concepts, and import.

Settings, model selection, indexing details, and backup are secondary tools. They
remain reachable from the settings shortcut and Organizar, but are not primary
navigation. Light and dark themes share the same persistent browser preference.
