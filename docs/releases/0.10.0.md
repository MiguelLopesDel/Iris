# Iris 0.10.0

## Changes since 0.9.0

### Updates
- The server checks for new releases every six hours. Administrators see the
  running and newest versions under **Settings › Updates**, with an
  **Update now** button.
- The Android app offers newer releases at the top of the gallery and hands the
  APK to the system installer. Android asks for confirmation.
- Updates no longer run a full backup first. An update replaces code and images
  and never touches the originals; the daily backup covers the data.

## Deployment

Run `./scripts/server.sh update` from the production installation. It no longer
backs up first; run `./scripts/server.sh backup` before it if you want a fresh
backup.

To update from the web interface from now on, enable the update agent once on
the server:

```bash
./scripts/server.sh updater install
```

Install the 0.10.0 APK over the previous one: it is the first version that
offers the following releases by itself.

## Release validation

This release was tagged without the staging checklist in `docs/process.md`.
After deploying, run the post-update check from that document: confirm the
version, `./scripts/server.sh status`, and that the app opens and syncs.
